
# Job Board Applications Analysis

## Overview
Analysis of 1,200 student job applications received between July and September 2026.

## Objectives
1. Identify the most effective recruitment acquisition sources.
2. Measure the relationship between application completion and shortlisting.
3. Compare employer response times for paid and unpaid roles.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Execution Instructions

1. Download or clone this repository.
2. Install the required dependencies:

   pip install pandas numpy matplotlib seaborn openpyxl jupyter

3. Keep the CSV file in the same directory as the notebook.
4. Open the notebook:

   jupyter notebook

5. Run all cells from top to bottom.

## Key Findings

- Referral generates 10.74 hires per 100 applications.
- Completing all four application steps is associated with a 48.39% shortlisting rate.
- Unpaid roles have a median response time of 7 days versus 3 days for paid roles.
- 29.61% of unpaid-role applicants have no recorded first reply.

## Output
The notebook generates visualisations, analysis tables, business recommendations and an Excel workbook.
